# Changelog

The package version is the pgmorbac extension version it ships. Extension
changes are in the [pgmorbac changelog](https://github.com/crudylabs/pgmorbac/blob/master/CHANGELOG.md).

## [1.0.0] - 2026-10-03

### Added
- The install and upgrade scripts of the signed pgmorbac 1.0.0 release, verified
  against the pinned release key when the package is built.
- `extensionSql()`, `upgradeScripts()`, `version`, `sqlDir` and `controlFile`.
